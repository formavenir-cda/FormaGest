# FormaGest
Application web de gestion pédagogique pour Form’Avenir : cursus, promotions, cours, inscriptions et calendriers élèves.



## Socle UI

Le projet utilise **Angular Material** comme bibliothèque de composants UI.

Ce choix a été retenu pour :

- son intégration native avec Angular ;
- ses composants adaptés aux besoins de FormaGest, notamment les formulaires,
  tableaux, dialogues et éléments de navigation ;
- sa bonne intégration avec les Reactive Forms ;
- la cohérence visuelle fournie par défaut ;
- la réduction du nombre de composants UI spécifiques à développer et maintenir.

Angular Material est privilégié par rapport à Bootstrap afin de rester au plus
près de l'écosystème Angular et de bénéficier de composants directement conçus
pour le framework.
